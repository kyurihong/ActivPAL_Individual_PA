# ActivPAL_Individual_PA

## Overview
This repository processes individual physical activity data collected from ActivPAL devices.

## Files
- 'main.R' – R script that processes the data and saves plots and summary files under 'output/' file.
- 'Activity Processing App.R' – A Shiny app version, designed to be user-friendly for those who are not comfortable with R studio. It allows users to get results through a simple interface.
- 'R/' – Contains the functions required by both 'main.R' and 'Activity Processing App.R'.

## Data Folders
The 'data/', 'output/', and 'sleep_diary/' folders are empty by default.
You need to add your own files into these folders before running the code.
